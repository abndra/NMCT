# سيرفر واتساب NMCT على Railway

واتساب عادي عبر مسح QR (Baileys) — بدون WhatsApp Business API وبدون أي رسوم لكل رسالة.

## الرفع على Railway
1. ارفع مجلد `whatsapp-server` كمستودع GitHub ثم: Railway › New Project › Deploy from GitHub.
2. Variables:
   - `TOKEN` = كلمة سر تخترعها (نفسها تُدخل في لوحة تحكم الموقع).
   - `FIREBASE_DB_URL` = `https://nmct-4d2a9-default-rtdb.firebaseio.com`
   - `ADMIN_NUMBER` = رقمك بصيغة دولية بدون + مثال `9689xxxxxxx`
   - `SESSION_DIR` = `/data/session`
3. أضف Volume على المسار `/data` (مهم: يحفظ الجلسة فلا يطلب QR بعد كل إعادة تشغيل).
4. افتح `https://<app>.up.railway.app/qr` وامسح الكود من واتساب › الأجهزة المرتبطة.
5. في لوحة تحكم الموقع › الإعدادات › «سيرفر الواتساب (Railway)» ضع الرابط والتوكن ثم «فحص الحالة».

## كيف يعمل
- الموقع يرسل الطلب الجديد لرقمك عبر `POST /send`.
- القبول والرفض والتسليم تتم من لوحة تحكم الموقع فقط. السيرفر لا يستجيب لأي رسائل واردة.

## التكلفة
استهلاك ~300–400MB RAM و CPU شبه معدوم ⇒ عملياً 3–5$ شهرياً على خطة Railway الأساسية،
والرسائل نفسها مجانية بالكامل مهما كان عددها.

## ⚡ التسليم الفوري للطلبات المدفوعة من الرصيد
الأكواد السرية لا يجوز أن يقرأها المتصفح (قواعد Firebase تمنع ذلك)، لذلك يقوم هذا السيرفر
بالسحب من المخزون وتسليم العميل تلقائياً عبر المسار `POST /deliver`.

### التفعيل
1. Firebase Console › Project settings › Service accounts › **Generate new private key** (ملف JSON).
2. في Railway › Variables أضف:
   - `FIREBASE_SERVICE_ACCOUNT` = محتوى ملف الـJSON كاملاً (أو نفسه بصيغة base64).
   - `FIREBASE_DB_URL` = `https://nmct-4d2a9-default-rtdb.firebaseio.com`
   - `STORE_NAME` = اسم المتجر (اختياري، يظهر في الرسائل).
3. أعد النشر ثم في لوحة التحكم › الإعدادات › «فحص الحالة» يجب أن تظهر: **التسليم الفوري مُفعّل ⚡**.

### كيف يعمل
- بعد خصم المبلغ من رصيد العميل وإنشاء الطلب، يستدعي الموقع `POST /deliver { idToken, orderId }`.
- السيرفر يتحقق من هوية العميل (Firebase ID token)، ويتأكد أن الطلب له وأنه مدفوع من الرصيد،
  ثم يسحب القطع من `stock/{productId}` بمعاملة ذرّية (لا تُباع القطعة مرتين)،
  ويحدّث الطلب بحالة **تم التسليم** مع الأكواد، ويرسل الأكواد للعميل وإشعاراً لك على الواتساب.
- إذا لم يُضبط مفتاح الخدمة، يرد السيرفر 501 ويبقى الطلب في لوحة التحكم "مدفوع" ليُسلَّم بضغطة قبول
  واحدة كما كان — لا يتأثر رصيد العميل.
- إذا نفد المخزون جزئياً: يُسلَّم المتوفر، ويبقى الطلب "جاري إكمال التسليم" ويصلك تنبيه بالنقص.
